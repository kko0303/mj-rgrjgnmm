# 雀卓スコア — セットアップ手順

手打ち麻雀の点棒・点数管理アプリです。iPadを卓の中央に置いて使います。
GitHub Pagesに置いてURLを共有すれば、全員がホーム画面に追加して使えます。

---

## 1. GitHubで公開する（10分）

1. GitHubにログインし、右上の **＋ → New repository**
2. Repository name を **推測しにくい名前** にして **Public** を選び、**Create repository**
   - これがそのままURLになります。`mahjong` のような名前は避け、`mj-k7q2x9fa` のようにランダムな文字を混ぜてください
   - この名前を知らない人はたどり着けません。**URLそのものが合鍵**だと思って扱ってください
3. 作られたページの **uploading an existing file** をクリック
4. このフォルダの中身をすべてドラッグ&ドロップして **Commit changes**
   - `index.html` / `config.js` / `manifest.json` / `sw.js` / `robots.txt` / `icon-192.png` / `icon-512.png`
   - `Code.gs` と `README.md` は無くても動きますが、一緒に置いておいて構いません
5. **Settings → Pages** → Source を **Deploy from a branch**、Branch を **main / (root)** にして **Save**
6. 1〜2分待つと `https://<ユーザー名>.github.io/<リポジトリ名>/` で開けます

**公開範囲について**

GitHub Pagesには「リンクを知っている人だけ」という設定がありません。リポジトリをPrivateにしても、公開されるサイト自体はPublicのままです（サイトを本当にPrivateにできるのはEnterprise Cloudの組織アカウントのみ）。

そのため守りは次の2つです。

- **推測しにくいURL** — 上の手順2。実質これが鍵です
- **検索避け** — `index.html` と `robots.txt` に設定済みなので、Googleなどの検索結果には出ません

URLをSNSやブログに貼らない限り、身内以外がたどり着く可能性はかなり低くなります。もし将来きちんと認証をかけたくなったら、Cloudflare Pages + Cloudflare Access（無料枠でメール認証、50人まで）に引っ越す方法があります。ファイルはそのまま使えます。

**ホーム画面への追加（各自の端末で1回）**
Safariでそのアドレスを開く → 共有ボタン → 「ホーム画面に追加」。
これで全画面のアプリとして起動し、オフラインでも動きます。

## 2. Googleスプレッドシートと連携する（15分）

履歴と通算成績が全員の端末で共有されるようになります。

1. Googleドライブで新しい **スプレッドシート** を作る（名前は何でも可）
2. **拡張機能 → Apps Script** を開く
3. 最初から入っているコードを消して、`Code.gs` の中身を貼り付ける
4. 1行目あたりの `var KEY = "change-me";` を好きな合言葉に変える
   例：`var KEY = "tendo2026";`
5. 右上の **デプロイ → 新しいデプロイ** → 歯車から **ウェブアプリ** を選ぶ
   - 説明：何でも可
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**
   - **デプロイ** を押し、初回は権限の確認画面で許可する
6. 表示された **ウェブアプリのURL**（`https://script.google.com/macros/s/.../exec`）をコピー
7. `config.js` を開いて、次のように書き換える

```js
window.JT_CONFIG = {
  endpoint: "ここにコピーしたURL",
  key: "手順4で決めた合言葉"
};
```

8. 書き換えた `config.js` をGitHubに上げ直す（同じファイル名でアップロードすれば上書きされます）

これで半荘が終わるたびに自動でシートに追記されます。
シートには4つのタブができます。

| タブ | 中身 |
|---|---|
| 対局結果 | 1半荘×1人で1行。順位・持ち点・ポイント・和了/放銃/リーチ/ツモ・平均和了点・平均放銃点・飛び・所要時間 |
| 通算成績 | 上を自動集計したランキング表 |
| _raw | アプリが読み戻すためのデータ。触らないでください |
| _state | 名簿・よみ・ボイス・ルール・進行中の対局。触らないでください |

通算成績はアプリの **「成績」** ボタンからも見られます。他の端末で打った分も、開いたときに自動で読み込まれます。

### 期間で絞る・精算する

成績画面の上に期間の切り替えがあります。

**全期間 ／ 直近24時間 ／ 直近3日 ／ 直近7日 ／ 直近30日 ／ 期間を指定**

選んだ期間だけで合計pt・平均順位・和了率などが再集計され、その下に **精算表**（誰が誰に何pt渡すか）が出ます。やり取りの回数が最小になるように組んであるので、そのまま清算できます。

### レートと五捨六入

**設定 → レート** で、1ptあたりの換算額と単位（コイン・円など）を決めます。

| 選択肢 | 1pt |
|---|---|
| なし（ptのみ） | 換算しない |
| 点5 | 50 |
| 点ピン | 100 |
| 点2 | 200 |
| 点3 | 300 |
| 点5百 | 500 |
| 自由入力 | 好きな数字 |

決めておくと、精算表・成績表・半荘終了時の画面すべてに換算額が並びます。レートは後から変えても、過去の記録に遡って再計算されます。

**五捨六入**（設定 → ルール、初期値オン）

素点の千点未満を、500点以下は切り捨て・600点以上は切り上げます。32,700点なら +3、32,500点なら +2 です。

この方式は計算上どうしても1ptの誤差が出ることがあるため、**その誤差は1位が被る**ようにしてあります。合計が必ずゼロになるので、精算表がそのまま使えます。小数点まで正確に出したい場合は、五捨六入をオフにしてください。

**「結果をコピー」** を押すとテキストになるので、LINEなどにそのまま貼れます。

```
【麻雀】全期間　1半荘　レート 1pt=100コイン
テストA +42pt　+4,200コイン（1半荘・平均順位1.00）
テストB +8pt　+800コイン（1半荘・平均順位2.00）
テストC -15pt　-1,500コイン（1半荘・平均順位3.00）
テストD -35pt　-3,500コイン（1半荘・平均順位4.00）
——— 精算 ———
テストD → テストA 35pt（3,500コイン）
テストC → テストA 7pt（700コイン）
テストC → テストB 8pt（800コイン）
```

### 端末をまたいで続きから始める

連携すると、次のものが全員の端末で共有されます。

- **名簿・よみ・ボイスの割り当て・ルール設定** — どれかの端末で登録すれば、他の端末を開いたときに自動で入ってきます。新しい端末でも、よみを入れ直す必要はありません
- **進行中の対局** — 別の端末で打ちかけの半荘があると、起動時に「別の端末に対局があります（東二局 1本場）」と聞かれます。「続きから開く」を押せば、その局・その点棒から再開できます

同じ人を別の端末で登録した場合は重複せず1人にまとめられ、よみやボイスを後から直した場合は、**新しく直したほうが優先されます**。

オフラインでも普通に使えます。つながったときに、たまっていた記録がまとめて送られます。

## 3. リーチボイスを差し替える

人ごとにリーチ音を変えられます。**メニュー → 名簿・リーチボイス** で、名前の横のプルダウンから選び、▶ で試聴できます。

最初から選べるもの：

- 読み上げ（標準／高め／低め／ゆっくり）— 「〇〇、リーチ」と端末が喋ります
- チャイムのみ
- 鳴らさない

### mp3を追加する（全員で共有する場合）

1. mp3を用意する（**1〜2秒・300KB以下**が目安。ファイル名は半角英数字）
2. `voices/` フォルダに入れて、GitHubにアップロードする
3. `voices.json` を編集して、入れたファイルを書く

```json
{
  "voices": [
    { "id": "v1", "label": "こういち用", "file": "voices/riichi1.mp3" },
    { "id": "v2", "label": "銅鑼",       "file": "voices/dora.mp3" }
  ]
}
```

4. アプリを開き直すと、プルダウンに出てきます

`voices.json` に書いてもファイルが無い行は、自動的に一覧から外れます。使わない行は消して構いません。

### 名前の読み方を直す

端末の読み上げは、漢字の名前をよく読み間違えます（森谷 → 「モリタニ」など）。

**名簿・リーチボイス** の各行にある **「よみ」** 欄にカタカナを入れると、そちらで読み上げます。席決め画面の新規登録にも「よみ」欄があるので、登録時にまとめて入れられます。

入れなければ名前をそのまま読みます。ニックネームや英数字の名前なら、たいてい不要です。

### 自分の声を録音する（いちばん手軽）

**メニュー → 名簿・リーチボイス** の「録音してボイスを作る」で、名前を入れて ● 録音 → ■ 停止。最大6秒で自動停止します。友人それぞれに自分の「リーチ！」を吹き込んでもらうと、卓が一番盛り上がります。

録音はその端末に保存されます。全員の端末で鳴らしたい場合は、録音したものを `voices/` に置く方法（下記）を使ってください。

### 動画（mp4）から音だけ使う

**mp4・mov も、そのまま選べます。** アプリが音声だけを取り出すので、事前に音声ファイルへ変換する必要はありません。

同じ画面の下にある **「音を追加」** で、

1. **開始（秒）** — 動画のどこから使うか（例：12.5）
2. **長さ（秒）** — 何秒ぶん切り出すか（既定3秒、最大10秒）
3. ファイルを選ぶ

長い動画でも、指定した部分だけを小さな音声に変換して保存します。前後のプツッという音が出ないよう、自動でフェードをかけています。

保存されるのはその端末だけです。他の人の端末では鳴りません。全員で同じ音にする場合は、上の `voices/` フォルダの方法を使ってください（mp4をそのまま `voices/` に置くこともできますが、動画のぶん容量が無駄になるので、mp3に変換してから置くことをすすめます）。

### mp3を追加する（自分の端末だけ）

音声ファイル（mp3・m4a・wav）も同じ「音を追加」から選べます。

### 全員の割り当てを揃える

各自が選んだ内容はその端末に保存されます。最初から全員同じにしておきたい場合は、`config.js` に既定値を書きます。

```js
window.JT_CONFIG = {
  endpoint: "...",
  key: "...",
  voiceMap: { "こういち": "v1", "はなわ": "v2" },
  yomiMap:  { "森谷": "モリヤ", "日下部": "クサカベ" }
};
```

端末側で選び直せば、そちらが優先されます。

## 4. 使い方

- **席決め** — 起動したら各席をタップして名簿から選びます。いない人は「新規登録」ですぐ追加できます
- **点差** — 各席に ▲ 上の着順との差、▼ 下の着順との差が出ます。オーラスの着順争いはここを見ます
- **和了** — 和了った人の席の「ツモ」か「ロン」を押します。ロンなら他の3人が赤い「放銃」ボタンに変わるので、振り込んだ人を押す → 得点入力 → 次へ → 支払いを確認 → 次の局へ
- **ダブロン・トリプルロン** — 得点入力画面の名前の右にある「＋和了者」から二人目を追加します（設定で有効にした場合）
- **サイコロ** — 局が始まるたびに自動で振られ、取る人の卓側が10秒だけ青く点滅します。実物を使う場合は「振り直す」で合わせられます
- **リーチ** — 宣言するとその人の側に点棒が置かれ、設定したボイスが鳴ります
- **流局** — 右下の「流局」を押すと各席が テンパイ／ノーテン のボタンに変わります。**リーチしていた人は自動でテンパイ固定**になるので、残りの人だけ押してください
- **取り消し** — 直前の操作を戻します（何手でも戻れます）
- **画面を回す** — 入力画面を90度ずつ回転。卓のどの位置からでも操作できます

## 5. 注意

- **`voices/` に入れてよい音** — 自分たちで録音したもの、権利上配布が許可されている効果音など。ゲームやアニメから取り出したボイスを `voices/` に入れると、公開サイトでの再配布になってしまうので入れないでください（各自の端末に「ファイルから追加」で取り込むぶんには、外に出ません）
- URLを知っている人は `config.js` の中身（Apps ScriptのURLと合言葉）も見られます。リポジトリをPrivateにしても、ページ自体は誰でも開けるので状況は変わりません。書き込まれて困るのは麻雀の点数だけなので実害は小さいですが、気になる場合はスプレッドシート側で定期的に確認してください
- 記録は各端末にも保存されます。シートに送れなかった分は、次に「シートと同期」を押したときにまとめて送られます
